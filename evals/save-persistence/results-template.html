What makes these trials comparable—and what does not

Same app fixture, skill snapshot, task, grading rules, Node and Playwright versions. Each agent started in fresh context with its own disposable app directory. Neither received the intended bug or repair.

Different agent harnesses, system instructions and dates. Both effort settings are called “high”; compute equivalence is unknown. Browser caches and host state were not reset. One trial each, with no no-skill baseline: no reliability, speed, cost or model-ranking claim.

More tests does not mean a better score. A failed test on the broken app is expected evidence, not an eval failure. The same regression must pass on the repaired app.
